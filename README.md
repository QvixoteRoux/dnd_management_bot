# dnd_management_bot
Discord bot to manage DnD Inventory and probably character stats

# Descripcion:

La idea de este proyecto es crear un bot con la API de discord para facilitar el manejo de inventario de objetos en partidad de DnD. Incluyendo el manejo de recompensas tras cada mision, looteo, compra / venta de objetos etc. Agregando tambien al registro la cartera de cada personaje, experiencia total y posiblemente los rasgos y estadisticas de cada personaje. Posiblemente agregando consola de administracion web.

Tentativamente se usaria python base como lenguaje y MongoDB para gestion de datos.
